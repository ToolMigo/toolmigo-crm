# ToolMigo briefpapier

Open `voorbeeld.html` in een browser voor de eerste A4-opzet. Kies afdrukken naar PDF met A4, schaal 100%, marges `geen` en achtergrondafbeeldingen ingeschakeld.

De bedrijfs-, KvK-, btw- en bankgegevens zijn bewust placeholders totdat de definitieve gegevens zijn aangeleverd. Het CRM vult documenttype, klant, regels, datums, bedragen, paginanummers en voorwaarden dynamisch in.

Het actieve beeldmerk is `../assets/toolmigo-logo.jpeg`, aangeleverd door de eigenaar. De woordnaam wordt daarnaast als tekst weergegeven, zodat deze op PDF's scherp en goed leesbaar blijft.
